# Remember this

Every session starts from zero unless you write something down. Your `MEMORY.md` is
the small, curated set of facts that make the next session smarter — not a transcript.

## Where memory goes

| What | Where | Who reads it |
| --- | --- | --- |
| Durable fact about how this org works | your profile `MEMORY.md` | you, next session |
| A deliverable | the knowledge base (`save-to-knowledge`) | humans + all profiles |
| Something every profile must know | draft for `00-org/ORG.md`, hand to Marketing Director | everyone |
| A reusable procedure | a new skill, or an update to `06-playbooks/` | everyone |

If it belongs to the organization rather than to your working style, it does **not**
belong in `MEMORY.md` — it belongs in the knowledge base where humans can see it.

## Worth remembering

- Decisions and their reasons: "They rejected the discount angle — brand policy, not preference."
- Stable constraints: "Legal review is required for anything naming Competitor X."
- What worked: "Case-study format with the metric in the H1 got approved first pass."
- What failed and why: "Long-form LinkedIn posts underperformed; they want 120 words max."
- People and cadence: "Weekly retro is Friday; the CMO reads only the top three lines."

## Not worth remembering

- Anything already written in `ORG.md`, the Brand Kit, or a playbook — memory that
  duplicates the knowledge base goes stale and then contradicts it.
- Facts about a single deliverable — those live with the deliverable.
- Anything you'd have to re-verify anyway (metrics, prices, live platform state).
- Personal data, credentials, or anything under NDA. Never.

## Steps

1. **Ask what changed.** If the session taught you nothing durable, write nothing.
   An empty memory beats a padded one.
2. **Write one fact per entry**, in a sentence that will still parse in six months.
   Date anything time-bound: "As of 2026-07, the ESP is Klaviyo."
3. **Update, don't append duplicates.** If an entry on this topic exists, revise it.
4. **Delete what turned out to be wrong.** A stale memory is worse than no memory.
5. **Say what you saved**, in one line, so the human can correct it immediately.

## Quality bar

- [ ] Each entry is one fact, self-contained, and dated if time-bound
- [ ] Nothing duplicates `ORG.md`, the Brand Kit, or a playbook
- [ ] No credentials, personal data, or confidential terms
- [ ] Entries that are now false were removed, not left to rot
