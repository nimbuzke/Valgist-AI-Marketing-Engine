# Character limits by destination

Reference table. Limits change — verify against the platform's current spec before a
build, and correct this file when you find a drift.

| Asset | Limit |
| --- | --- |

| Google callout extension | 25 |
| Google sitelink text | 25 |
| Google sitelink description | 35 |
| Microsoft Ads headline | 30 |
| Microsoft Ads description | 90 |

## Email

| Asset | Recommended | Note |
| --- | --- | --- |
| Subject line | 30–45 | Mobile truncates ~35 |
| Preheader | 40–90 | Never leave it to auto-fill |
| Sender name | ≤23 | Consistency beats cleverness |
| CTA button | 2–4 words | Verb first |

## SMS / push

| Asset | Limit | Note |
| --- | --- | --- |
| SMS single segment (GSM-7) | 160 | 153 per segment when concatenated |
| SMS single segment (UCS-2, emoji) | 70 | One emoji halves your budget |
| Push title | 40 | Android truncates earlier |
| Push body | 120 | iOS shows ~110 |

Opt-out language ("Reply STOP to opt out") counts against the limit. Budget for it
before writing, not after.
