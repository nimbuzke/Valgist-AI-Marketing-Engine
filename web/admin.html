About

This dashboard is administration only. It stores the organization's knowledge — plain Markdown under knowledge/ — and runs the four jobs the chat front end can't: it rebuilds INDEX.md (the catalogue every profile reads first), keeps the work-order queue, records review verdicts, and is the only path that can write the read-only organization brain.

To actually use the AI Marketing Engine, open Valgist WebUI and pick a profile from the composer footer. Its workspace is this same knowledge base.

No integration is wired. The community edition ships no connector code and no credentials, so profiles cannot reach analytics, ad platforms, CRMs or ESPs. They work from files you put in the knowledge base and mark everything else [AWAITING DATA] — by design, so nothing invented reaches a board deck.
