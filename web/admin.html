About

This dashboard is administration only. It stores the organization's knowledge and the critical outputs each Hermes profile needs — every artifact lives as plain Markdown under knowledge/, categorized for humans, and the 31 profile definitions are synced from here into Hermes Agent profile homes.

To actually use the AI Marketing Engine, open Hermes WebUI and pick a profile from the composer footer. Its workspace is this same knowledge base.
